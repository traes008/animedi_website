# Animedi single-page prototype

A dependency-free, responsive **single-page** prototype for the Animedi veterinary clinic.
All sections (departments, practice, approach, contact, appointments) live on one scrolling page.

This is a separate early prototype. The full multi-page website lives in
[`../animedi-multipage-preview/`](../animedi-multipage-preview/) and is not based on this file.

## View locally

Double-click `index.html`, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`. Assets are included locally, so the site works offline
(with system font fallbacks when Google Fonts are unavailable).

## Share

Send `animedi-preview.zip` from the parent folder. Unzip and open `index.html`.
